## Локальная сборка

```sh
npm ci
node --test tools/step-greek.test.mjs tools/step-greek-rest.test.mjs
node tools/step-greek-rest.mjs --export-local
```

На локальном компьютере появится `work/step-greek-acts-revelation.db`, папка `work/` игнорируется Git. Файл **не** публикуется в исходном репозитории, Release или CI artifacts. Вместе с уже проверенной SQLite Евангелий (`ST-GR`) образует полный корпус TAGNT по книгам, но не подтверждает пословное соответствие русскому переводу.

**Для Android:** отдельный код `ST-GR2`, покрытие книг 510–730. Старый `ST-GR` (470–500) не менять. Не включать этот файл в APK без корректной атрибуции STEP Bible и локального предупреждения об объёме/лицензии. Совместимость с существующим механизмом `interlinear` проверять отдельным CI.
