# Брокгауз: подготовка словаря

Подтверждено наличие «Библейской энциклопедии Брокгауза» в каталоге BibleQuote:
https://github.com/BibleQuote/BibleQuote-Modules/blob/master/modules.ini
Это **не** дореволюционный словарь Брокгауза и Ефрона. Русский перевод Ф. Ринекера / Г. Майера публиковался с 1999 года, поэтому наличие в каталоге не является свободной лицензией.

## Готово: локальная конвертация MyBible

Для файла, в котором есть таблица `dictionary(topic, definition)`:

```sh
npm ci
node tools/inspect-dictionary.mjs /local/source.dictionary.SQLite3
node tools/convert-dictionary.mjs /local/source.dictionary.SQLite3 /local/converted.db --name "Библейская энциклопедия Брокгауза" --code BRK --language ru
npm test
```

Конвертер не обращается к сети, не перезаписывает оригинал или существующий результат, проверяет SQLite и наличие статей, сохраняет текст и внутреннюю HTML-разметку, а также пишет `info(type=dictionary, app_format=1)`.
Результат — локальный SQLite-файл, **не** общедоступный релиз. Непроверенная лицензия маркируется `unverified`.
Не коммитить `*.SQLite3`/результат с текстами издания в репозиторий и не включать в `catalog.json` до письменного разрешения на распространение. Не рендерить HTML статьи как доверенный код: при интеграции использовать безопасный текстовый вывод или санитайзер.
