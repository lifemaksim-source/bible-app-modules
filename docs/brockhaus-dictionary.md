# Брокгауз: предварительная проверка модуля

Цель: добавить «Библейскую энциклопедию Брокгауза» как скачиваемый словарь, пользуясь существующим механизмом модулей. **Не включать текст словаря в Git, APK или публичный Release до получения разрешения на распространение.**

## Следующий практический шаг

1. Получить законным способом файл SQLite/MyBible и подтвердить право его использовать и распространять в приложении. Онлайн-доступность или наличие в стороннем каталоге не равны лицензии.
2. Локально выполнить `npm ci`, затем `node tools/inspect-dictionary.mjs /path/to/dictionary.db`.
3. Проверить `integrity: ok`, таблицы, названия столбцов и количество записей. Утилита не выводит содержимое статей и не изменяет файл.
4. По реальной схеме добавить **один** преобразователь в текущую сборку и запись типа `dictionary` в каталог, только после согласования лицензии.
5. Подключить поиск по заголовку и открытие статьи через существующую библиотеку. Не добавлять автопривязку к каждому стиху до появления надёжного сопоставления.

Источник: Ф. Ринекер, Г. Майер, «Библейская энциклопедия Брокгауза», русское переводное издание (1999 и последующие переиздания). Это **не** дореволюционный словарь Брокгауза и Ефрона.

## Передача Claude

Пока не интегрировать в APK: опубликованного разрешённого словарного модуля нет. После проверки схемы и прав использовать текущий загрузчик модулей, отдельный тип `dictionary`, RU/EN подписи и существующий UI библиотеки; избегать дополнительных зависимостей.
