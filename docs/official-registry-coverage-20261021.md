### Реальные ограничения

- `dar/DRG`: реестр маркирует даргинским, а поле SQLite `info.language='Dargi'` — человеческое название, а не код. Повторный аудит **подтвердил** одну книгу и 1068 непустых стиховых строк (3 пустые), SHA-256 `ccc788ccc619bb57ad99d8b23feaea08e1c115ea1d3ec08efb860ff6164f9471`. Это явно разрешённый псевдоним `dar`, который оставляет предупреждение; ни в коем случае не считать модуль полной Библией.
- В реестре по проверенным кодам не оказалось записей, например, для `ab`, `abk`, `agx`, `ava`, `ckt`, `rut`, `tab`. Это *не* означает, что не существуют внешние цифровые переводы: см. отдельно кандидатов PH4/DBS.
- Проект приложения уже использует официальный MyBible registry. **Не нужно переносить эти 442 записи в собственный каталог и создавать второй механизм скачивания.** Реальные ZIP доступны из текущего `registry.zip`.
- В репозиторий/Release/APK библейские двоичные файлы не добавлены. Для проверки каждого из остальных 398 модулей нужны отдельные данные и Android QA.
