# Техническая проверка русскоязычных модулей MyBible

**Дата:** 16 октября 2026 года. **Источник:** официальный MyBible [registry.zip](https://mybible.zone/repository/registry/registry.zip). Проверено без публикации исходных SQLite/ZIP и текстов статей.

В реестре выявлены **49 словарных модулей** и **60 модулей комментариев** с языком `ru`. Это количество записей реестра, а не число материалов с подтверждёнными правами.

## Результат реального запуска

| Модуль | Название | Статей / записей | SQLite/схема |
|---|---|---:|---|
| `Имена.dictionary` | Значение библейских имён | 691 | OK |
| `Нюстрем.dictionary` | Библейский энциклопедический словарь Э. Нюстрема | 2 718 | OK |
| `Брокгауз.dictionary` | Библейская энциклопедия Брокгауза (Ринекер, Майер) | 4 754 | OK |
| `БТ-к.commentaries` | Библия тематическая с комментариями | 52 | OK |
| `Баркли-к.commentaries` | Комментарии к Новому Завету Баркли | 1 440 | OK |

**CI:** [реальный тест пяти модулей](https://github.com/lifemaksim-source/bible-app-modules/actions/runs/38958111156), [быстрые тесты](https://github.com/lifemaksim-source/bible-app-modules/actions/runs/38958111122) — успешно.

У трёх словарей: целостность SQLite, столбцы `topic/definition`, ненулевое число статей, отсутствие проблем в `auditDictionary`. У двух комментариев: целостность SQLite, ожидаемые поля диапазонов и текстовое поле, ненулевое число записей, отсутствие NULL/нетекстовых значений `text`.

**Сведения об интеллектуальных правах:** у всех пяти исследованных SQLite **отсутствуют заполненные поля** `info.license`, `info.attribution`, `info.origin/homepage`. В нашем реестровом сканировании у этих позиций тоже не найдено явных полей лицензии. Отсутствие метаданных — не доказательство того, что произведение защищено; и, наоборот, доступность на MyBible — не право на распространение в коммерческом приложении.

**Решение:** пока не включать эти тексты в публичный `catalog.json`, GitHub Releases или клиентскую APK. Следующий юридический этап — документировать правообладателей *конкретных изданий и русских переводов*, отдельно выяснять условия разрешённого распространения и монетизации.

## Ограничения аудита

- Проверялась читаемость SQLite и основные столбцы. Содержательная точность текстов, цитат и ссылок пока не подтверждена.
- Для словарного поиска по **склонённым русским словоформам** требуется отдельная проверка таблицы `words` и её вариантов `standard_form/variation`: тест выше её не выполнял.
- Проверка была разовой и выполнялась только на CI: при изменении файлов на серверах MyBible результат нужно пересмотреть.
- Для Android-приложения нужен отдельный smoke-тест импорта/чтения, не меняющий интерфейс Claude.

Скрипты: `tools/mybible-ru-scan.mjs`, `tools/mybible-ru-live-qa.mjs`; материалы оставались только во временном каталоге GitHub runner.
