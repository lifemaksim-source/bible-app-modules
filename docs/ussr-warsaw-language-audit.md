# Аудит языков бывшего СССР, Варшавского договора, Югославии и Монголии

Дата: 2026-10-21. Статус: начальная инвентаризация; **не** перечень готовых переводов.

## Правило отбора
- Пользовательский каталог показывает язык, только если для него есть хотя бы один реально скачиваемый библейский модуль (включая отдельную книгу).
- Приоритет: уже опубликованные модули; затем готовые MyBible SQLite; затем цифровые источники, которые можно конвертировать.
- Не создавать пустые языковые разделы и не объявлять существование печатного издания доказательством доступного цифрового файла.
- Таджикский (tg) и монгольский (mn) — обязательные приоритеты поиска.
- Лицензию и происхождение записывать как метаданные; исследование и локальные тесты не блокировать, публичное распространение оценивать отдельно.

## Проверенный исходный снимок
`catalog.json` ветки `main` репозитория `lifemaksim-source/bible-app-modules` (updated: 2026-10-15) содержит **5 библейских модулей, все с language=en**: WEB, BSB, ASV, BBE, MSB. Остальные элементы: crossrefs, strongs, комментарий Лопухина (ru). **Ни таджикского, ни монгольского скачиваемого перевода в этом снимке нет.** Другие ветки и внешние каталоги требуют отдельной проверки.

## Обязательные поля для каждой следующей находки
`languageTag`, `languageName`, `script`, `translationTitle`, `sourceUrl`, `sourceFormat`, `booksAvailable`, `versesAvailable`, `downloadUrl`, `sha256`, `licenseStatus`, `conversionStatus`, `androidTestStatus`.
