Дата: 2026-10-21. Статус: начальная инвентаризация; **не** перечень готовых переводов.

## Правило отбора
- Пользовательский каталог показывает язык, только если для него есть хотя бы один реально скачиваемый библейский модуль (включая отдельную книгу).
- Приоритет: уже опубликованные модули; затем готовые MyBible SQLite; затем цифровые источники, которые можно конвертировать.
- Не создавать пустые языковые разделы и не объявлять существование печатного издания доказательством доступного цифрового файла.
- Таджикский (tg) и монгольский (mn) — обязательные приоритеты поиска.
- Лицензию и происхождение записывать как метаданные; исследование и локальные тесты не блокировать, публичное распространение оценивать отдельно.

### Проверка реальных SQLite-файлов без изменения базы

Добавлен инструмент без внешних зависимостей: `tools/inspect_mybible.py`.

```sh
python3 tools/inspect_mybible.py '/путь/к/Ариун Библи.SQLite3'
python3 -m unittest discover -s tools -p test_inspect_mybible.py -v
```

Инструмент открывает SQLite **только для чтения**; проверяет сигнатуру, `PRAGMA quick_check`, таблицы `info/books/verses`, непустой текст, отсутствие повторов, правильные положительные координаты и наличие книг для стихов. Он выдаёт JSON с составом и диагностическим образцом стиха. Результат `structural_only_not_published` **не** означает, что нумерация подтверждена, весь текст точен или Android-подключение прошло.

**Тесты инструмента на синтетических базах:** 5/5 локально; реальные архивы из PH4 пока не удалось проверить в этой среде, поэтому в каталоге не опубликовано ни одной новой записи.

## Продолжение 21 октября: география и надёжность проверки

- Реестр расширен до **48 записей на 36 языках** (включая три прежних draft). Дополнены туркменский, македонский, словацкий, словенский, сербский, хорватский, литовский; повторяющийся крымскотатарский вариант исключён по ID.
- Основание для новых внешних кандидатов — [индекс MyBible PH4](https://www.ph4.org/b4_my.php). Это доказательство **наличия записи о файле**, не подтверждение работоспособности самого файла. В частности, в PH4 прямо указано, что скачивается ZIP с SQLite3.
- Уточнён SQLite-инспектор: база открывается с `mode=ro&immutable=1`, дополнительно выдаётся `sha256` конкретного файла. Локально заново проверены **5/5 Python unit-тестов**, включая совпадение SHA-256.
- Сеть контейнера не разрешает DNS для ph4.org и github.com. Поэтому **реальные ZIP не скачаны** и **ни один новый модуль не опубликован**. Не подменять отсутствие доступа утверждением об отсутствии переводов.
- Перед выпуском файла по-прежнему обязательны реальная загрузка ZIP, проверка SQLite, нумерации, соответствия языку и Android.
