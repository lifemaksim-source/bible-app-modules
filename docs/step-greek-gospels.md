# Источник греческого подстрочника: STEP Bible TAGNT (черновой импорт)

**Основание:** [STEP Bible data](https://github.com/STEPBible/STEPBible-Data), файл `TAGNT Mat-Jhn` (Евангелия), версию и SHA исходного Git blob фиксирует `sources-step-greek.json`. Лицензия набора **CC BY 4.0**; атрибуция: STEP Bible / Tyndale House Cambridge. Уточнять лицензию других наборов отдельно (например, `TTESV` содержит пометку `CC BY-NC`; смешивать права файлов нельзя).

**Почему так:** TAGNT — объединение нескольких греческих изданий. Скрипт выбирает **только** токены, помеченные как принадлежащие изданию `SBL`, и оставляет исходные греческие формы и морфологические пометы STEP Bible. Это **отбор слов SBL**, но **не** гарантированная посимвольная реконструкция печатного текста SBLGNT. Суффиксы расширенного Стронга сохраняются, не заменяются догадками; русский перевод с греческими словами автоматически не совмещается.

**Техническая проверка:**
```sh
npm ci
node --test tools/step-greek.test.mjs
node tools/step-greek.mjs --sqlite-smoke
```

Последняя команда скачивает **только закреплённую версию** исходного STEP Bible TAGNT в оперативную память, проверяет SHA Git blob, разметку четырёх Евангелий, номера глав и стихов по нашей нумерации `eng`, сохранность номеров Стронга и морфологии, собирает временный SQLite в памяти, проверяет целостность и число строк. В логах — только счётчики, SHA и сведения о лицензии, **без текстов стихов**. В GitHub не попадают ни исходник, ни SQLite-файлы.

**Следующий этап после успешной проверки:** отдельно подключить импортированный слой к Android UI, добавить второй файл TAGNT (Деяния–Откровение), затем еврейский TAHOT и тщательную проверку Ketiv/Qere и стиховой нумерации. Не смешивать с KJV Strong (другая исходная традиция), не обещать буквальную привязку русских слов. Синопсис и хронология — самостоятельные проверяемые наборы данных.

Не добавлять этот эксперимент в `catalog.json` и не публиковать релиз без отдельной проверки.
