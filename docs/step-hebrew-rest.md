# STEP Bible TAHOT — оставшиеся 34 книги Ветхого Завета

Это **отдельный аудит продолжения** [первой части (Бытие–Второзаконие)](./step-hebrew-audit.md). База: STEPBible-Data `94802ced31e63882ab42a86d79eb0017df4545e3`, лицензия исходного набора CC BY 4.0, атрибуция STEP Bible / Tyndale House Cambridge. Состав и Git blob SHA-1 взяты из официального репозитория и закреплены в `sources-step-hebrew.json`.

| Файл исходника | Книги | Цель аудита |
|---|---:|---|
| `TAHOT Jos-Est` | 12 | Исторические книги — Иисус Навин–Есфирь |
| `TAHOT Job-Sng` | 5 | Иов, Псалтирь, Притчи, Екклесиаст, Песнь Песней |
| `TAHOT Isa-Mal` | 17 | Пророки — Исаия–Малахия |
| **Итого** | **34** | Совместно с Gen–Deu охватит 39 книг ВЗ |

`tools/step-hebrew-rest.mjs` повторно использует исходный row-preserving парсер и проверку закреплённых байтов из предыдущего PR. Код не содержит библейских текстов. Каждый файл проверяется **по закреплённому Git blob SHA-1 и размеру**, SHA-256 всех четырёх частей **уже закреплены** в манифесте по успешным запускам и проверяются на каждом последующем. Обязательны все книги и **каждая глава** по канону проекта; длину стихов из KJV/Синодального перевода не приравниваем к еврейской. Проверяется исходное количество TSV-полей (17), сохраняются все поля с указателями Ketiv/Qere, без интерпретации, и создаётся временная SQLite-база с `PRAGMA quick_check`. Файлы SQLite нигде не публикуются и не загружаются как artifacts.

`#501` и аналогичные индексы — **индексы TAHOT**, а не гарантированные порядковые номера слов. Изменение названия документа или наличие букв K/Q не определяет главное чтение: при подготовке UI оба варианта должны иметь источниковую подпись.

## Граница ответственности

Это проверка **целостности, покрытия и воспроизводимости исходника**, а не подтверждение богословской безошибочности или стопроцентной академической корректности всех лемм. Для пользовательского подстрочника потребуются правила чтения исходных меток, выбор текстологической традиции, проверка особенностей арамейских фрагментов Ездры и Даниила, греческо-еврейская и русская нумерация, а также выборочная экспертная сверка.

Автоматический импорт не выполняет морфологического «угадывания», не соединяет еврейские слова с русским переводом, не дополняет строки ИИ. Релиз/добавление текстов в GitHub не входит в этот PR. Merge в `main` — только с разрешения владельца.

Вместе с Gen–Deu: **39 книг, 929 глав, 305 648 исходных строк**. «Все главы» означает присутствие минимум одной размеченной записи в каждой главе, **не** подтверждает отсутствие всех возможных лакун в стихах или согласованность с русской нумерацией.

**Зафиксированные SHA-256** (на точной версии STEP Bible):

- Jos–Est: `195fee1dc3653bab33701f170734eb894ed647c10cd08cc61749375fe8b73775`
- Job–Sng: `bb508af3af07822fca84cc43a0eba79eb70eecf672aabc0245b8d8cecf329d96`
- Isa–Mal: `f3ded203d2a74d6368932c97ae550d1d0754b271af491dc0dedf36fe3ba0bcc5`

**Важные аномалии и их обработка:**

- Исторические книги Jos–Est: **7** записей с меткой `Q(K)` без обычной еврейской поверхности.
- Пророки Isa–Mal: ещё **7** таких записей.
- Псалтирь Job–Sng: **478 записей** с исходным адресом стиха `0` — надписания псалмов. Число *записей* не равно числу псалмов с надписанием.
- 17 столбцов TAHOT сохранены для каждой исходной записи; поля, семантику которых не установили, остаются в `extra_columns`.
- Во всех трёх файлах `malformed=0` **после** сохранения указанных особых случаев. Их не отбрасывали и не превращали в фиктивные слова.

Все аудиты и SQLite `PRAGMA quick_check` успешно завершились. Эти результаты отражают **техническую целостность** входных данных, а не экспертную верификацию каждого текстологического решения.
